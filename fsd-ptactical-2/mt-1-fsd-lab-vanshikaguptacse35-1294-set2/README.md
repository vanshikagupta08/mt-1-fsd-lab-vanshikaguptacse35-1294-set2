# FSD_MT01_Vanshika_Gupta_CSE35_1294_Batch2

### Project Title: Library Book Management API

### Technologies Used : Express.js , Node.js

### About Project :
A RESTful API developed using Node.js and Express.js to manage library book records in server memory. It supports full CRUD operations along with input validation, HTTP status code handling, and case-insensitive author filtering.

### Requests :
GET-/api/books
POST-/api/books
GET-/api/books/:id
PUT-/api/books/:id
DELETE-/api/books/:id
GET-/api/books/filter?author=value
